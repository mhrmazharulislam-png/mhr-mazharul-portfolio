BEFORE PUBLISHING
1. Replace YOUR_EMAIL@example.com in index.html with your real professional email.
2. Replace the three sample project artwork tiles in index.html with your own project images and captions.
3. Add your Fiverr and LinkedIn profile links when ready.
4. Review all text and service offerings before publishing.

CLOUDFLARE PAGES DEPLOYMENT (STATIC SITE)
1. Create/sign in to a Cloudflare account: https://dash.cloudflare.com/sign-up
2. Create a GitHub repository and upload index.html, style.css and script.js to the repository root.
3. In Cloudflare Dashboard, open Workers & Pages > Create > Pages > Connect to Git.
4. Select your repository.
5. Framework preset: None. Build command: leave blank. Build output directory: /
6. Deploy. Cloudflare will provide a *.pages.dev address.
7. Future commits to the connected branch can trigger deployments automatically.

This is a static HTML/CSS/JS site. No paid framework or build step is required.
Hosting plan terms and limits can change; check Cloudflare's current Pages plan terms before commercial use.
